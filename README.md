# PopSearch

**PopSearch** — веб-приложение для поиска и представления знаний о музыкальных исполнителях поп-жанра. Система объединяет сведения собственной базы данных PostgreSQL с данными открытых музыкальных каталогов и интернет-источников.

Проект разработан в рамках курсовой работы по дисциплине «Проектирование баз знаний».

## Возможности

- **Поиск исполнителей, песен и альбомов.** Поддерживаются запросы по имени исполнителя, названию композиции или альбома, в том числе частичные совпадения. Результаты локальной базы и iTunes объединяются с устранением повторяющихся карточек.
- **Уточнение исполнителя.** Карточка артиста открывает поиск по его полному отображаемому имени. Для получения дискографии и публикаций используются данные установленного исполнителя, чтобы не смешивать сведения одноимённых артистов.
- **Тематическая фильтрация.** Внешние результаты отбираются с учётом подтверждённой принадлежности исполнителя к поп-музыке.
- **Дискография.** Отображаются альбомы и композиции, а также сведения о релизах, доступные в базе знаний или музыкальных каталогах.
- **Публикации.** В одной вкладке представлены два раздела: «Об исполнителе» (справочные материалы, в том числе из Википедии) и «Свежие новости» (Google News RSS).
- **Изображения.** Фотографии подбираются с помощью Wikidata и Wikimedia Commons. Доступен полноэкранный просмотр и переход к странице источника.
- **Видео.** Отображаются материалы базы знаний и результаты YouTube при наличии API-ключа.
- **Постраничное расширение выдачи.** Кнопка «Показать ещё результаты» подгружает дополнительные результаты без полной перезагрузки страницы.

В интерфейсе предусмотрены вкладки **«Все», «Исполнители», «Альбомы», «Песни», «Публикации», «Видео», «Изображения»**.

## База знаний

В PostgreSQL используются следующие основные таблицы:

| Таблица | Назначение |
| --- | --- |
| `artists` | Исполнители и их основные сведения |
| `subgenres` | Поджанры поп-музыки |
| `albums` | Альбомы исполнителей |
| `album_subgenres` | Связи альбомов и поджанров |
| `songs` | Музыкальные композиции |
| `album_songs` | Связи композиций и альбомов |
| `materials` | Локальная подборка статей, изображений и видеоматериалов |

Основной жанр **pop** задаёт предметную область базы и не дублируется отдельной записью в `subgenres`. Для получения производных знаний используются SQL-представления:

- `v_inferred_artist_subgenres` — поджанры исполнителя, определяемые по его альбомам;
- `v_inferred_artist_songs` — композиции исполнителя, определяемые через принадлежность альбомам;
- `v_inferred_song_subgenres` — поджанры песен, определяемые через альбомы.

Таким образом, часть связей не дублируется при хранении, а получается из уже существующих отношений между сущностями.

## Установка и запуск

### 1. Требования

- Python 3.13 или совместимая версия Python 3 с поддержкой зависимостей из `requirements.txt`;
- PostgreSQL;
- доступ к интернету для обращения к внешним источникам.

### 2. Подготовка окружения

Перейдите в каталог `web`:

```powershell
cd PopSearch\web
```

Создайте виртуальное окружение (рекомендуется):

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```powershell
python -m pip install -r requirements.txt
```

> Если PowerShell запрещает активацию виртуального окружения, команды можно выполнять непосредственно через `.venv\Scripts\python.exe`.

### 3. Подготовка PostgreSQL

Создайте отдельную пустую базу данных. Например:

```sql
CREATE DATABASE popsearch_final;
```

Подключитесь к новой базе и выполните скрипты в следующем порядке:

1. `sql/01_schema.sql` — создание объектов базы знаний;
2. `sql/02_seed.sql` — заполнение справочника поджанров;
3. `sql/04_content.sql` — загрузка основных данных.

При необходимости после заполнения запустите `sql/05_content_check.sql` для проверки записей и связей. `sql/03_test_queries.sql` содержит дополнительные диагностические запросы; он не обязателен для запуска приложения.

**Если база данных уже настроена и заполнена, повторно создавать схему и выполнять SQL-скрипты не требуется.** Скрипт наполнения рассчитан на повторный запуск без дублирования исходных записей, но не предназначен для автоматического исправления ранее созданных некорректных связей.

### 4. Настройка конфигурации

Скопируйте файл `web/.env.example` в `web/.env` и укажите параметры своей базы:

```dotenv
DB_HOST=localhost
DB_PORT=5432
DB_NAME=popsearch_final
DB_USER=postgres
DB_PASSWORD=ваш_пароль

MUSICBRAINZ_USER_AGENT=PopSearch/1.0 (contact: your-email@example.com)
YOUTUBE_API_KEY=
```

Для MusicBrainz укажите корректный `User-Agent` с контактной информацией. `YOUTUBE_API_KEY` нужен для получения внешних результатов YouTube; без него остаются доступны локальные видеоматериалы. Переменные `FLASK_DEBUG` и `FLASK_PORT` могут использоваться в конфигурации, однако в текущем `app.py` режим отладки явно отключён, а порт по умолчанию равен `5055`.

**Не публикуйте `.env` в GitHub или распространяемых архивах.** Для передачи настроек используйте `.env.example` без секретов.

### 5. Запуск

Из каталога `web` выполните:

```powershell
python app.py
```

Затем откройте в браузере:

**http://127.0.0.1:5055**

Для остановки сервера нажмите `Ctrl+C`.

## Как работает поиск

1. Пользователь вводит имя исполнителя, название песни или альбома.
2. `search.py` запрашивает локальные сведения из `database.py` и, при необходимости, внешние источники через специализированные модули.
3. Результаты проверяются по релевантности и поп-жанру, объединяются и очищаются от дубликатов.
4. Для установленного исполнителя могут дополнительно загружаться обложки, фотографии, новости и видео.
5. Flask передаёт подготовленные данные в `index.html`, а JavaScript управляет взаимодействием со страницей.

При совпадении запроса с именем исполнителя и названием композиции карточка исполнителя получает приоритет во вкладке «Все», но подходящие песни сохраняются в результатах.

## Ограничения

- Полнота результатов зависит от доступности, правил поиска и ограничений внешних API. Частичное совпадение не гарантирует нахождение каждого исполнителя или релиза.
- Некоторые фотографии Wikimedia Commons могут отсутствовать, если их метаданные не содержат необходимой связи с исполнителем.
- Свежие новости зависят от ответа Google News RSS и могут отсутствовать за выбранный период.
- Доступность YouTube зависит от API-ключа и квоты сервиса; результаты поиска не обязательно являются официальными видео исполнителя.
- Приложение запускается на встроенном сервере Flask, предназначенном для локальной разработки и демонстрации, а не для промышленного развёртывания.

## Назначение проекта

PopSearch демонстрирует построение тематической базы знаний: хранение структурированных сведений о предметной области, представление взаимосвязей между исполнителями, альбомами, композициями и поджанрами, получение производных знаний средствами SQL и дополнение локальной информации данными внешних источников.
